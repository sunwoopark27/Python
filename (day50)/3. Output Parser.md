- Output Parser
    
    ## 1. 출력파서란 무엇인가?
    
    출력파서는 LangChain 프레임워크에서 언어 모델(LLM)의 출력을 더 유용하고 구조화된 형태로 변환하는 핵심 컴포넌트입니다. 일반적으로 LLM은 자유 형식의 텍스트를 생성하지만, 실제 애플리케이션에서는 이 텍스트를 구조화된 형태(JSON, 리스트, 객체 등)로 변환해야 할 경우가 많습니다. 출력파서는 이 변환 과정을 자동화하여 개발 효율성을 높여줍니다.
    
    ## 2. 출력파서의 핵심 역할
    
    - **형식 변환**: LLM의 텍스트 출력을 구조화된 데이터로 변환
    - **일관성 유지**: 일관된 출력 형식을 보장하여 후속 처리 용이
    - **오류 처리**: 잘못된 출력 형식에 대한 오류 감지 및 처리
    - **프롬프트 최적화**: 특정 형식의 출력을 유도하는 프롬프트 생성 지원
    
    ## 3. 출력파서의 종류
    
    LangChain은 다양한 출력파서를 제공하며, 각 파서는 특정 사용 사례에 최적화되어 있습니다:
    
    ### 3.1 기본 출력파서
    
    - **StringOutputParser**: 가장 단순한 형태로, LLM 출력을 문자열로 반환
    - **ListOutputParser**: 출력을 리스트 형태로 변환
    - **CommaSeparatedListOutputParser**: 쉼표로 구분된 항목을 리스트로 변환
    
    ### 3.2 구조화된 출력파서
    
    - **JSONOutputParser**: 출력을 JSON 형식으로 파싱
    - **PydanticOutputParser**: Pydantic 모델을 사용하여 출력 검증 및 변환
    - **XMLOutputParser**: XML 형식으로 출력 변환 및 파싱
    
    ### 3.3 특수 목적 파서
    
    - **RouterOutputParser**: 다양한 출력 형식을 조건에 따라 다른 파서로 라우팅
    - **RetryOutputParser**: 파싱 실패 시 재시도 로직 구현
    - **TransformOutputParser**: 출력을 사용자 정의 함수를 통해 변환
    
    ## 4. 출력파서 사용 실습
    
    ### 4.1 기본 출력파서 사용 예제
    
    ```python
    from langchain.output_parsers import CommaSeparatedListOutputParser
    from langchain.prompts import PromptTemplate
    from langchain.llms import OpenAI
    
    # 출력 파서 정의
    parser = CommaSeparatedListOutputParser()
    
    # 파서 지시사항 포함한 프롬프트 생성
    format_instructions = parser.get_format_instructions()
    prompt = PromptTemplate(
        template="한국의 유명한 관광지를 나열해주세요.\\n{format_instructions}",
        input_variables=[],
        partial_variables={"format_instructions": format_instructions}
    )
    
    # LLM 모델 정의
    llm = OpenAI(temperature=0)
    
    # 프롬프트 실행 및 결과 파싱
    _input = prompt.format_prompt()
    output = llm(_input.to_string())
    parsed_output = parser.parse(output)
    
    print(parsed_output)  # ['경복궁', '남산타워', '제주도', '해운대', '설악산', ...]
    
    ```

    ### 4.3 Pydantic 출력파서 예제
    
    ```python
    from langchain.output_parsers import PydanticOutputParser
    from langchain.prompts import PromptTemplate
    from langchain.llms import OpenAI
    from pydantic import BaseModel, Field
    from typing import List
    
    # Pydantic 모델 정의
    class MovieRecommendation(BaseModel):
        title: str = Field(description="영화 제목")
        director: str = Field(description="영화 감독")
        year: int = Field(description="개봉 연도")
        genres: List[str] = Field(description="영화 장르 목록")
        summary: str = Field(description="영화 줄거리 요약")
    
    # Pydantic 출력 파서 정의
    parser = PydanticOutputParser(pydantic_object=MovieRecommendation)
    
    # 프롬프트 템플릿 생성
    prompt = PromptTemplate(
        template="사용자가 액션 영화를 좋아합니다. 추천할만한 영화를 알려주세요.\\n{format_instructions}",
        input_variables=[],
        partial_variables={"format_instructions": parser.get_format_instructions()}
    )
    
    # LLM 모델 정의
    llm = OpenAI(temperature=0.7)
    
    # 프롬프트 실행 및 결과 파싱
    _input = prompt.format_prompt()
    output = llm(_input.to_string())
    parsed_output = parser.parse(output)
    
    print(f"제목: {parsed_output.title}")
    print(f"감독: {parsed_output.director}")
    print(f"개봉 연도: {parsed_output.year}")
    print(f"장르: {', '.join(parsed_output.genres)}")
    print(f"줄거리: {parsed_output.summary}")
    
    ```
    
    ## 5. 출력파서 사용 시 주의사항
    
    1. **모델 온도 설정**: 구조화된 출력을 얻기 위해서는 낮은 temperature 값(0~0.3)을 사용하는 것이 좋습니다.
    2. **명확한 지시사항**: 파서가 기대하는 형식을 명확하게 프롬프트에 포함시켜야 합니다.
    3. **오류 처리**: 파싱 실패에 대비한 예외 처리 로직을 구현해야 합니다.
    4. **토큰 제한 고려**: 복잡한 구조를 파싱할 경우 LLM의 토큰 제한을 고려해야 합니다.
    5. **검증 로직 추가**: 중요한 애플리케이션에서는 파싱된 결과에 대한 추가 검증 단계를 구현하는 것이 좋습니다.

    5. **실패 처리**: 파싱 실패 시 적절한 오류 메시지와 대응 전략 구현 가능

    ## 9. 맞춤형 출력파서 개발하기
    
    ```python
    from langchain.output_parsers import BaseOutputParser
    from typing import List
    
    class CustomListOutputParser(BaseOutputParser):
        """항목을 번호가 매겨진 리스트로 파싱하는 파서"""
    
        def parse(self, text: str) -> List[str]:
            """텍스트를 파싱하여 리스트로 반환"""
            # 줄별로 나누기
            lines = text.strip().split('\\n')
            # 숫자로 시작하는 줄만 선택 (예: "1. 항목")
            items = []
            for line in lines:
                line = line.strip()
                # 번호가 있는 항목 찾기 (예: "1.", "2.", 등)
                import re
                match = re.match(r'^\\d+\\.\\s+(.+)$', line)
                if match:
                    items.append(match.group(1))
            return items
    
        def get_format_instructions(self) -> str:
            """파서 사용 지침을 반환"""
            return (
                "응답은 다음과 같은 형식이어야 합니다:\\n"
                "1. 첫 번째 항목\\n"
                "2. 두 번째 항목\\n"
                "..."
            )
    
    ```
    
    ## 10. 결론 및 모범 사례
    
    LangChain의 출력파서는 LLM 기반 애플리케이션 개발에 있어 중요한 도구입니다. 이를 통해 개발자는 LLM의 출력을 보다 효과적으로 활용하고, 구조화된 데이터로 쉽게 변환할 수 있습니다.
    
    ### 모범 사례:
    
    1. **명확한 지침**: LLM에게 원하는 출력 형식에 대한 명확한 지침 제공
    2. **단순성 유지**: 가능한 단순한 구조로 설계하여 LLM이 쉽게 따를 수 있게 함
    3. **점진적 접근**: 복잡한 구조보다는 여러 단계의 단순한 파싱으로 분할
    4. **오류 처리**: 파싱 실패에 대비한 전략 구현
    5. **테스트**: 다양한 입력과 조건에서 출력파서 테스트
