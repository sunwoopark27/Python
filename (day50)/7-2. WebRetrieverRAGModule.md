파일 WebRetriever.py
- WebRetrieverRAGModule
    
    이 코드는 웹 검색 기능을 수행하는 RAG(Retrieval-Augmented Generation) 모듈을 구현합니다. 사용자의 질문에 대한 정보를 웹에서 검색하여 챗봇 응답을 강화하는 역할을 합니다.
    
    ## 코드 구조 및 기능
    
    1. **임포트 섹션**:
        
        ```python
        import os
        from langchain_community.tools.tavily_search import TavilySearchResults
        from module import BaseRAGModule, State
        
        ```
        
        - `os`: 환경 변수에 접근하기 위한 표준 라이브러리
        - `TavilySearchResults`: Tavily API를 통한 웹 검색 기능 제공
        - `BaseRAGModule`, `State`: 기본 RAG 모듈 클래스와 상태 관리 클래스 (로컬 모듈에서 임포트)
    2. **클래스 정의**:
        
        ```python
        class WebRetrieverRAGModule(BaseRAGModule):
            node_id = "web_retriever"
        
        ```
        
        - `BaseRAGModule`을 상속받아 웹 검색 전용 모듈 구현
        - `node_id`: 모듈 식별자 정의 ("web_retriever")
    3. **핵심 메서드 - run**:
        
        ```python
        def run(self, state: State) -> State:
        
        ```
        
        - 입력: 현재 상태(`state`) 객체
        - 출력: 웹 검색 결과가 추가된 상태 객체
        - 타입 힌팅을 통해 입출력 타입을 명확히 함
    4. **실행 과정**:
        
        - 실행 알림 출력
        - API 키 확인
        - 웹 검색 실행 및 결과 처리
        - 예외 상황 처리
    5. **API 키 관리**:
        
        ```python
        tavily_api_key = os.environ.get("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")
        if not tavily_api_key:
            # API 키 없음 처리
        
        ```
        
        - 환경 변수에서 Tavily API 키를 가져옴
        - 키가 없는 경우 오류 메시지를 상태에 저장하고 함수 종료
    6. **검색 실행**:
        
        ```python
        tavily_search_tool = TavilySearchResults(max_results=1)
        results = tavily_search_tool.invoke({"query": state["question"]})
        
        ```
        
        - 최대 1개의 결과를 반환하도록 검색 도구 초기화
        - 상태 객체의 "question" 필드를 쿼리로 사용하여 검색 실행
    7. **결과 처리**:
        
        ```python
        contents_list = [r["content"] for r in results]
        state["data"] = contents_list
        
        ```
        
        - 검색 결과에서 "content" 부분만 추출하여 리스트로 저장
        - 이 리스트를 상태 객체의 "data" 필드에 저장
    8. **예외 처리**:
        
        ```python
        except Exception as e:
            print(f"웹 검색 중 오류 발생: {str(e)}")
            state["data"] = "웹 검색 중 오류가 발생했습니다. 관련 정보를 찾을 수 없습니다."
        
        ```
        
        - 모든 예외를 포착하여 오류 메시지 출력
        - 오류 발생 시 적절한 메시지를 상태 객체에 저장
    
    이 모듈은 RAG 시스템의 검색 컴포넌트로, 사용자 질문에 대한 관련 정보를 웹에서 찾아 챗봇의 응답 생성에 활용할 수 있게 합니다.
