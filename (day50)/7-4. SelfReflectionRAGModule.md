파일 self_reflection_module.py
- SelfReflectionRAGModule
    
    이 모듈은 생성된 답변의 품질을 평가하는 자기성찰(Self-RAG) 기능을 구현합니다. 코드의 각 부분을 상세히 분석해보겠습니다.
    
    ## 1. 임포트 부분
    
    ```python
    from langchain_core.output_parsers import JsonOutputParser, StrOutputParser
    from langchain_core.prompts import ChatPromptTemplate
    from module import BaseConditionalEdgeModule, State
    
    ```
    
    - **JsonOutputParser**: LLM의 응답을 JSON 형식으로 파싱
    - **StrOutputParser**: LLM의 응답을 문자열로 파싱
    - **ChatPromptTemplate**: LLM에 전달할 메시지 템플릿 생성
    - **BaseConditionalEdgeModule**: 조건부 경로 결정을 위한 기본 모듈 클래스
    - **State**: 데이터와 상태를 관리하는 클래스
    
    ## 2. 클래스 정의 및 초기화
    
    ```python
    class SelfReflectionRAGModule(BaseConditionalEdgeModule):
        edge_id = "self_reflection"
    
        def __init__(self, llm, route_llm):
            self.llm = llm
            self.route_llm = route_llm
    
    ```
    
    - **edge_id**: 모듈 식별자로 "self_reflection" 사용
    - **llm**: 주요 응답 생성에 사용되는 언어 모델
    - **route_llm**: 답변 품질 평가용 언어 모델 (경로 결정에 사용)
    
    ## 3. 메인 평가 메서드 - judge_answer
    
    ```python
    def judge_answer(self, state: State) -> str:
        print("---답변 퀄리티 검증 (Self-RAG)---")
    
        # 답변이 항상 통과하도록 설정 (항상 높은 품질로 간주)
        print("---답변 검증 완료: 높은 품질로 판단됨---")
        return "yes"
    
    ```
    
    - 현재 구현은 모든 답변을 높은 품질로 간주하여 무조건 "yes" 반환
    - 주석 처리된 이전 코드가 원래의 상세 평가 로직을 포함
    - 실제 평가에서는 답변의 진실성, 지지성, 유용성을 모두 검토
    
    ## 4. 주석 처리된 평가 로직

    ```python
    '''
    try:

    else:
        status = "진실이 아닙니다" if hallucinated else "진실입니다"
        print(f"---주어진 답변은 {status}.---")

    else:
        return "no"
    '''
    
    ```
    
    - **try-except 구조**: 필요한 상태 데이터가 없는 경우 처리
    - **조건 판단**: 지지성 또는 유용성이 있고, 할루시네이션이 아닌 경우 "yes" 반환
    - **기본 동작**: 기준을 충족하지 못하면 "no" 반환 (재검색 또는 수정 필요)
    
    ## 5. 지지성 평가 메서드 - _is_answer_supportive
    
    ```python
    def _is_answer_supportive(self, state: State) -> bool:
        # 생성된 텍스트가 질문과 관련이 있는지 확인합니다.
        question = state["question"]
        generation = state["generation"]
        system_message = """당신은 AI의 답변이 사용자의 질문에 대한 해답인지 평가하는 평가자입니다."""
    
        # 메시지 구성 설명...
        user_message = """사용자의 질문: {question}
        AI의 답변: {generation}
        AI의 답변이 사용자의 질문에 대한 해답이면 'yes', 아니라면 'no'를 선택하세요.
        'answer' key 하나만 있는 JSON 형식으로 답변하고, 다른 텍스트나 설명을 생성하지 마세요."""
    
        message_list = [("system", system_message)]
        message_list.append(("human", user_message))
    
        relevant_judge_prompt = ChatPromptTemplate.from_messages(message_list)
        # LangChain 체인 설정
        router_chain = relevant_judge_prompt | self.route_llm | JsonOutputParser()
    
        result = router_chain.invoke({"question": question, "generation": generation})
        if result["answer"] == "yes":
            return True
        return False
    
    ```
    
    - **프롬프트 구성**: 시스템 메시지와 사용자 메시지로 구성
    - **메시지 템플릿**: 질문과 답변을 포함하는 템플릿 생성
    - **파이프라인 구성**: 프롬프트 → LLM → JSON 파서의 체인 형성
    - **결과 처리**: "answer" 키의 값이 "yes"이면 True 반환, 아니면 False 반환
    - **특이 사항**: 함수 이름과 달리 결과값은 'supportive'가 아닌 'answer' 키에 저장 (주석에 설명)
    
    ## 6. 유용성 평가 메서드 - _is_answer_useful
    
    ```python
    def _is_answer_useful(self, state: State) -> bool:
        # 생성된 텍스트가 질문에 대한 해답인지 확인합니다.
        question = state["question"]
        generation = state["generation"]
        system_message = (
            """당신은 AI의 답변이 사용자에게 유용한지 평가하는 평가자입니다."""
        )
        user_message = """사용자의 질문: {question}
        AI의 답변: {generation}
        AI의 답변이 사용자에게 유용하다면 'yes', 아니라면 'no'를 선택하세요.
        'useful' key 하나만 있는 JSON 형식으로 답변하고, 다른 텍스트나 설명을 생성하지 마세요."""
    
        # 지지성 평가와 유사한 구현...
        message_list = [("system", system_message)]
        message_list.append(("human", user_message))
    
        useful_judge_prompt = ChatPromptTemplate.from_messages(message_list)
        router_chain = useful_judge_prompt | self.route_llm | JsonOutputParser()
    
        result = router_chain.invoke({"question": question, "generation": generation})
        if result["useful"] == "yes":
            return True
        return False
    
    ```
    
    - 지지성 평가와 유사한 구현이지만 다른 프롬프트와 결과 키 사용
    - **평가 기준**: 생성된 답변이 사용자에게 유용한지 여부
    - **결과 처리**: "useful" 키의 값이 "yes"이면 True 반환, 아니면 False 반환

    ```python
        generation = state["generation"]

        # 항상 할루시네이션이 아닌 것으로 판단 (즉, 항상 정확한 정보로 판단)
    ```

    - 현재 구현은 항상 False 반환 (항상 할루시네이션이 아닌 것으로 판단)
    - 주석 처리된 코드는 검색된 문서와 답변을 비교하여 진실성 평가
    
    ## 8. 주석 처리된 할루시네이션 평가 로직
    
    ```python
    '''
    system_message = """당신은 주어진 근거 문서를 바탕으로 AI의 답변이 진실인지 여부를 평가하는 평가자입니다."""
    user_message = """근거 문서: {docs}
    AI의 답변: {generation}
    근거 문서를 바탕으로 AI의 답변이 진실이라면 True, 아니라면 False를 선택하세요.
    'answer` key 하나만 있는 JSON 형식으로 답변하고, 다른 텍스트나 설명을 생성하지 마세요."""
    
    message_list = [("system", system_message)]
    message_list.append(("human", user_message))
    
    hallucination_judge_prompt = ChatPromptTemplate.from_messages(message_list)
    router_chain = hallucination_judge_prompt | self.route_llm | JsonOutputParser()
    
    result = router_chain.invoke({"generation": generation, "docs": docs})
    print(result)
    if result["answer"] == "True":
        return True
    return False
    '''
    
    ```
    
    - **평가 방식**: 검색된 문서(docs)와 생성된 답변(generation)을 비교
    - **프롬프트**: LLM에게 답변이 근거 문서에 기반한 진실인지 평가 요청
    - **결과 처리**: "answer" 키의 값이 "True"이면 할루시네이션으로 판단
    - 다른 메서드와 달리 "True/False" 문자열을 사용 (다른 메서드는 "yes/no" 사용)
    
    ## 주요 패턴 및 기법
    
    1. **파이프라인 패턴**:
        - LangChain의 `|` 연산자를 사용한 파이프라인 구성
        - `prompt | model | parser` 형태로 데이터 흐름 구성
    2. **메타평가(Meta-evaluation)**:
        - LLM이 다른, LLM의 출력을 평가하는 메타평가 패턴
        - 자기평가(self-evaluation)를 통한 품질 관리
    3. **구조화된 출력**:
        - JSON 형식의 응답 요청으로 결과 처리 용이
        - 명확한 키 값으로 평가 결과 식별
    4. **예외 처리**:
        - 필요한 상태 데이터가 없는 경우를 대비한 try-except 구조
        - 기본값 설정으로 견고성 확보
    
    이 모듈은 RAG 시스템에서 생성된 답변의 품질을 자동으로 평가하고, 필요시 다른 경로(재검색, 답변 수정 등)로 분기할 수 있게 해주는 중요한 구성 요소입니다.
