    # 모듈 기본 구조 및 LLMAnswerRAGModule 코드 설명
    
    이 코드는 RAG(Retrieval-Augmented Generation) 시스템의 기본 구조를 정의하고, LLM을 사용한 답변 생성 모듈을 구현합니다. 코드를 세부적으로 분석해보겠습니다.
    
    ## 1. State 클래스
    
    ```python
    class State(TypedDict):
        # 그래프 상태의 속성을 정의합니다.
        # 질문, LLM이 생성한 텍스트, 데이터, 코드를 저장합니다.
        question: str
        generation: str
        data: str
        code: str
    
    ```
    
    - **TypedDict 상속**: Python의 타입 힌팅을 위한 `TypedDict`를 사용
    - **속성 정의**:
        - `question`: 사용자 질문
        - `generation`: LLM이 생성한 답변 텍스트
        - `data`: 검색된 참고 데이터
        - `code`: 생성된 코드 (필요한 경우)
    - **목적**: 워크플로우의 각 단계 사이에서 데이터를 전달하는 컨테이너 역할
    
    ## 2. BaseRAGModule 클래스
    
    ```python
    class BaseRAGModule:
        # 각 모듈은 LangGraph Workflow의 노드 역할을 합니다.
        node_id: str
    
        # 각 모듈은 다음 노드로 전달할 데이터를 반환하는 `run` 메서드를 가져야 합니다.
        def run(self, state: State) -> State:
            raise NotImplementedError
    
        def __call__(self, state: State) -> State:
            return self.run(state)
    
    ```
    
    - **추상 기본 클래스**: 모든 RAG 모듈의 기본 형태 정의
    - **node_id**: 각 모듈의 고유 식별자
    - **run 메서드**:
        - 모듈의 핵심 동작을 구현
        - NotImplementedError 발생시켜 하위 클래스에서 구현 강제
    - **call 메서드**:
        - 모듈 객체를 함수처럼 호출 가능하게 함
        - 내부적으로 run 메서드 호출
    
    ## 3. BaseConditionalEdgeModule 클래스
    
    ```python
    class BaseConditionalEdgeModule:
        edge_id: str
    
        def run(self, state: State) -> str:
            raise NotImplementedError
    
    ```
    
    - **조건부 경로 제어**: 워크플로우의 조건부 흐름을 담당
    - **edge_id**: 조건부 간선의 고유 식별자
    - **run 메서드**:
        - State를 입력으로 받아 문자열 반환
        - 반환된 문자열에 따라 워크플로우의 다음 단계 결정
    
    ## 4. LLMAnswerRAGModule 클래스
    
    ```python
    class LLMAnswerRAGModule(BaseRAGModule):
        def __init__(self, llm):
            self.node_id = "llm_answer"
            self.llm = llm
    
        def run(self, state: State) -> State:
            question = state["question"]
            data = state["data"]
    
            # LLM을 사용하여 검색된 데이터를 기반으로 답변 생성
            prompt = f"""다음 정보를 참고하여 질문에 답변하세요:
    
    질문: {question}
    
    참고 정보: {data}
    
    다음 지침을 반드시 따라주세요:
    1. 반드시 한국어로 답변해주세요.
    2. 참고 정보에 기반하여 정확하게 답변해주세요.
    3. 전문적인 내용이라도 이해하기 쉽게 설명해주세요.
    4. 불필요한 영어 표현은 피하고 가능한 한 한글로 설명해주세요.
    5. 답변은 논리적이고 체계적으로 구성해주세요.
    6. 필요한 경우 예시를 들어 설명해주세요.
    
    한국어로 상세하게 답변해주세요.
    """
            response = self.llm.invoke(prompt)
    
            # 응답 결과를 state에 저장하고 반환
            state["generation"] = response.content
            return state
    
    ```
    
    - **BaseRAGModule 상속**: 기본 모듈 클래스 확장
    - **초기화**:
        - `node_id`를 "llm_answer"로 설정
        - LLM 모델 객체 저장
    - **run 메서드 구현**:
        1. State에서 질문과 검색된 데이터 추출
        2. 프롬프트 구성:
            - 질문과 검색된 데이터 포함
            - 답변 형식에 대한 명확한 지침 제공 (한국어 사용, 정확성, 이해 용이성 등)
        3. LLM을 사용한 답변 생성
        4. 생성된 답변을 State의 "generation" 필드에 저장
        5. 업데이트된 State 반환
