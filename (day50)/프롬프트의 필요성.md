## 프롬프트의 필요성

1. **문맥(Context) 설정**: 언어 모델이 특정 상황에 맞게 작동하도록 환경을 조성합니다. 이를 통해 모델은 주어진 정보를 기반으로 더 정확하고 관련성 높은 응답을 생성할 수 있습니다.
2. **정보 통합**: 다양한 출처에서 검색된 정보들은 서로 다른 관점이나 내용을 포함할 수 있습니다. 프롬프트는 이러한 정보를 통합하고, 모델이 효율적으로 활용할 수 있는 형태로 구성합니다.
3. **응답 품질 향상**: 모델의 응답 품질은 프롬프트 구성에 크게 의존합니다. 잘 설계된 프롬프트는 모델이 더 정확하고 유용한 정보를 제공하도록 돕습니다.

## RAG 프롬프트 구조

- **지시사항(Instruction)**: 모델에게 수행할 작업에 대한 안내
- **질문(사용자 입력 질문)**: 사용자가 제시한 질문
- **문맥(검색된 정보)**: 질문 해결에 필요한 검색된 정보

```yaml
당신은 질문-답변(Question-Answer) Task를 수행하는 AI 어시스턴트입니다.
검색된 문맥(context)를 사용하여 질문(question)에 답하세요.
만약, 문맥(context)으로부터 답을 찾을 수 없다면 '모른다'고 말하세요.
한국어로 대답하세요.

#Question:
{이곳에 사용자가 입력한 질문이 삽입됩니다}

#Context:
{이곳에 검색된 정보가 삽입됩니다}

```

## 프롬프트의 중요성

프롬프트 단계는 RAG 시스템의 핵심 요소입니다. 이 단계를 통해 언어 모델은 사용자의 질문에 대해 **최적화된 방식으로 응답을 생성**할 수 있으며, **시스템 전체의 성능과 사용자 만족도에 직접적인 영향**을 미칩니다.

프롬프트가 제대로 구성되지 않으면, 모델은 비효율적으로 동작할 수 있고, 결과적으로 사용자의 요구에 부합하지 않는 응답을 생성할 가능성이 높아집니다.

# LangChain 프롬프트 템플릿 활용 가이드

## PromptTemplate 사용 방법

### 1. from_template() 메소드를 활용한 방법

```python
from langchain_core.prompts import PromptTemplate

# 변수를 {변수명}으로 표시
template = "{country}의 수도는 어디인가요?"

# PromptTemplate 객체 생성
prompt = PromptTemplate.from_template(template)

# 변수 값 채우기
formatted_prompt = prompt.format(country="대한민국")
# 결과: '대한민국의 수도는 어디인가요?'

# 체인 생성 및 실행
chain = prompt | llm
result = chain.invoke("대한민국")

```

### 2. PromptTemplate 객체 직접 생성 방법

```python
template = "{country}의 수도는 어디인가요?"

# 입력 변수 명시적 지정
prompt = PromptTemplate(
    template=template,
    input_variables=["country"],
)

```

### 3. partial_variables 활용

```python
# 일부 변수만 고정하여 사용
prompt = PromptTemplate(
    template="{country1}과 {country2}의 수도는 각각 어디인가요?",
    input_variables=["country1"],
    partial_variables={"country2": "미국"}
)

# 부분 변수 수정
prompt_partial = prompt.partial(country2="캐나다")

```

### 4. 함수를 변수로 사용하기

```python
from datetime import datetime

def get_today():
    return datetime.now().strftime("%B %d")

prompt = PromptTemplate(
    template="오늘의 날짜는 {today} 입니다. 오늘이 생일인 유명인 {n}명을 나열해 주세요.",
    input_variables=["n"],
    partial_variables={"today": get_today}
)

```

### 5. 파일에서 템플릿 불러오기

```python
from langchain_core.prompts import load_prompt

prompt = load_prompt("prompts/fruit_color.yaml")

```

# FewShotPromptTemplate 활용 가이드

## 개요

FewShotPromptTemplate은 예시를 기반으로 AI 모델이 특정 패턴을 학습하도록 돕는 프롬프트 작성 기법입니다. 이를 통해 모델에게 작업 수행 방식을 구체적인 예시로 보여줌으로써 더 정확한 응답을 얻을 수 있습니다.

## 기본 사용법

```python
from langchain_core.prompts.few_shot import FewShotPromptTemplate
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 예시 데이터 정의
examples = [
    {
        "question": "스티브 잡스와 아인슈타인 중 누가 더 오래 살았나요?",
        "answer": """이 질문에 추가 질문이 필요한가요: 예.
추가 질문: 스티브 잡스는 몇 살에 사망했나요?
중간 답변: 스티브 잡스는 56세에 사망했습니다.
추가 질문: 아인슈타인은 몇 살에 사망했나요?
중간 답변: 아인슈타인은 76세에 사망했습니다.
최종 답변은: 아인슈타인
"""
    },
    # 추가 예시...
]

# 예시 프롬프트 형식 정의
example_prompt = PromptTemplate.from_template(
    "Question:\\n{question}\\nAnswer:\\n{answer}"
)

# FewShotPromptTemplate 생성
prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    suffix="Question:\\n{question}\\nAnswer:",
    input_variables=["question"],
)

# 체인 생성 및 실행
chain = prompt | llm | StrOutputParser()
result = chain.invoke({"question": "Google이 창립된 연도에 Bill Gates의 나이는 몇 살인가요?"})

```

## Example Selector 활용

Example Selector는 많은 예시 중에서 현재 질문과 가장 관련성 높은 예시를 선택하는 기능을 제공합니다.

```python
from langchain_core.example_selectors import SemanticSimilarityExampleSelector
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma

# Example Selector 생성
example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples,                  # 예시 목록
    OpenAIEmbeddings(),        # 임베딩 모델
    Chroma,                    # 벡터 스토어
    k=1,                       # 선택할 예시 수
)

# FewShotPromptTemplate에 Example Selector 적용
prompt = FewShotPromptTemplate(
    example_selector=example_selector,
    example_prompt=example_prompt,
    suffix="Question:\\n{question}\\nAnswer:",
    input_variables=["question"],
)

```

## FewShotChatMessagePromptTemplate 활용

대화형 응답을 위해 FewShotChatMessagePromptTemplate을 사용할 수 있습니다.

```python
from langchain_core.prompts import ChatPromptTemplate, FewShotChatMessagePromptTemplate

# 예시 프롬프트 형식 정의
example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{instruction}:\\n{input}"),
    ("ai", "{answer}"),
])

# FewShotChatMessagePromptTemplate 생성
few_shot_prompt = FewShotChatMessagePromptTemplate(
    example_selector=example_selector,
    example_prompt=example_prompt,
)

# 최종 프롬프트 구성
final_prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    few_shot_prompt,
    ("human", "{instruction}\\n{input}"),
])

```

## 유사도 검색 최적화

유사도 검색을 최적화하기 위해 커스텀 Example Selector를 구현할 수 있습니다.

```python
from langchain_teddynote.prompts import CustomExampleSelector

# 커스텀 Example Selector 생성
custom_selector = CustomExampleSelector(examples, OpenAIEmbeddings())

# 커스텀 FewShotChatMessagePromptTemplate 생성
custom_fewshot_prompt = FewShotChatMessagePromptTemplate(
    example_selector=custom_selector,
    example_prompt=example_prompt,
)

```

## 활용 사례

- 복잡한 추론 과정이 필요한 질문 답변
- 특정 형식의 문서 작성 (회의록, 요약, 교정 등)
- 단계별 사고 과정을 보여주는 문제 해결
- 일관된 응답 스타일 유지
