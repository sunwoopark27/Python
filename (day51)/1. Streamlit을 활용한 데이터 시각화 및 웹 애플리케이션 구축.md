## **1. 개요**

### 1.1. Streamlit 소개

- Python 기반의 웹 애플리케이션 프레임워크
- 빠르고 직관적인 데이터 시각화 및 대시보드 구축 가능
- 프론트엔드 지식 없이도 머신러닝 모델 및 데이터 분석 결과 공유 가능

### 1.2. 주요 특징

- 간단한 코드로 웹 앱 제작 가능 (`st.write()`, `st.dataframe()`, `st.plotly_chart()` 등)
- 핫 리로딩(Hot Reloading) 지원 → 코드 변경 즉시 반영
- Markdown, Chart, Table, Media 등 다양한 요소 제공
- 캐싱 기능을 통한 성능 최적화 가능 (`@st.cache_data`, `@st.cache_resource`)

## **3. Streamlit UI 요소**

### 3.1. 텍스트 출력

```python
st.title("제목")
st.header("헤더")
st.subheader("서브헤더")
st.text("일반 텍스트")
st.markdown("**마크다운 지원**")
st.code("print('Hello, Streamlit!')", language="python")

```

### 3.2. 입력 위젯

```python
name = st.text_input("이름을 입력하세요")
age = st.number_input("나이를 입력하세요", min_value=0, max_value=100)
agree = st.checkbox("동의하십니까?")
selected_option = st.radio("옵션 선택", ["A", "B", "C"])
multi_select = st.multiselect("여러 개 선택", ["옵션1", "옵션2", "옵션3"])
uploaded_file = st.file_uploader("파일 업로드")

```

### 3.3. 버튼 및 상호작용

```python
if st.button("클릭하세요"):
    st.write("버튼이 클릭되었습니다!")

if st.toggle("토글 버튼"):
    st.write("토글이 활성화되었습니다!")

```

## **5. Streamlit 상태 관리**

### 5.1. 세션 상태 (`st.session_state`)

```python
if "count" not in st.session_state:
    st.session_state.count = 0

if st.button("증가"):
    st.session_state.count += 1

st.write(f"현재 값: {st.session_state.count}")

```

### 5.2. 캐싱 (`@st.cache_data`, `@st.cache_resource`)

```python
import time

@st.cache_data
def expensive_function():
    time.sleep(3)
    return "완료!"

if st.button("실행"):
    result = expensive_function()
    st.write(result)

```

## **7. 실습 예제**

### 7.1. 데이터 분석 대시보드 만들기

**(예제: 타이타닉 데이터 분석 대시보드)**

```python
import streamlit as st
import pandas as pd
import plotly.express as px

st.title("타이타닉 데이터 분석 대시보드")

# 데이터 로드
df = pd.read_csv("<https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv>")

# 성별 생존율 시각화
fig = px.histogram(df, x="Sex", color="Survived", barmode="group")
st.plotly_chart(fig)

# 나이 분포 시각화
st.subheader("나이 분포")
fig_age = px.histogram(df, x="Age", nbins=30, color="Survived", barmode="overlay")
st.plotly_chart(fig_age)

```
