- 실습 문제 2: 주문 입력 시스템 만들기
    
    **목표**: 간단한 카페 주문 입력 시스템을 만들어보세요.
    
    **요구사항**:
    
    1. 앱 제목을 "카페 주문 시스템"으로 설정하세요.
    2. 주문자 이름을 입력받는 텍스트 입력 위젯을 추가하세요.
    3. 음료 선택을 위한 선택 상자를 추가하세요 (예: 아메리카노, 카페라떼, 카푸치노, 녹차).
    4. 음료 크기를 선택하는 라디오 버튼을 추가하세요 (small, medium, large).
    5. 옵션을 선택할 수 있는 여러 체크박스를 추가하세요:
        - 샷 추가
        - 휘핑크림 추가
        - 얼음 추가
    6. 수량을 선택할 수 있는 숫자 입력이나 슬라이더를 추가하세요.
    7. "주문하기" 버튼을 추가하고, 버튼을 클릭하면 전체 주문 내역을 요약하여 표시하세요.
    
    **도전 과제**: 선택한 메뉴와 옵션에 따라 총 가격을 계산하여 표시하는 기능을 추가해보세요.
